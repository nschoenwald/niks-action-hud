# Changelog

All notable changes to **Nik's Action HUD (`niks-action-hud`)** are documented in this file.

## [14.19.1] - 2026-10-25

- **Legendary menu**: Legendary actions that cast a spell (such as a dragon's *Fiery Rays* or *Commanding Presence*) are no longer listed twice. Only the action itself is shown, now with the spell's damage and range. The spell is still in the Spells menu.
- **NPC auto-pins**: These actions are now pinned as the action itself, not as a second copy of the spell they cast.

## [14.19.0] - 2026-10-25
